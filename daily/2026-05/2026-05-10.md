## 📢 话题一：PraestoClaw 1.1 正式发布

**发起人**：Coraline Gao · 2026-05-09 22:56  
**链接**：[一键安装](https://aka.ms/praestoclaw/install) | [官网](https://aka.ms/praestoclaw) | [GitHub Repo](https://github.com/gim-home/PraestoClaw)

**核心内容**：
PraestoClaw 1.1 正式上线，重点升级：

1. **🧠 Hermes 大脑**：从"会调工具"升级为"会规划、会并行执行、会压缩上下文、会做 provider failover"，长任务用 TODO/SOP 持续汇报进度
2. **📦 Skill & MCP 开箱即用**：直接操作 ADO / Teams / Outlook / OneDrive / GitHub / ICM；`pc init` 可自动导入 Claude Code / VS Code Copilot / Copilot CLI 的 skills 和 MCP 配置；连接 Societas / Edge / Copilot / PM Studio / Studio8 等 skill marketplace
3. **🧰 实战技能包**：内置 `feature-implement / bug-investigate / refactor-large / deep-research / doc-write / data-migration / megaphone / ms-search / societas-debug` 等 12+ 技能
4. **🛡️ 免养基建**：Windows 安装体验升级、autostart、自更新兜底、allowlist/risk-tier 加固
5. **🌐 Agent Gateway Foundation**：PraestoClawGateway 独立成 repo，落地 Native Agent Gateway Protocol + A2A visibility-based routing + 身份映射 + JIT access governance，为 v1.2 团队级 Agent 协作平台铺路

🧠 **解读 & 应用建议（Edge Mobile PM 视角）**：
PraestoClaw 1.1 的核心跃升在于**从工具调用者变成任务规划者**——Hermes 大脑让 Agent 能做真正意义上的多步任务分解。对 Edge Mobile PM 来说，最直接的价值：(1) `ms-search / megaphone / data-migration` 技能可以覆盖日常的内部信息检索和数据同步；(2) Teams/Outlook 集成让 PM 的邮件分类、会议摘要、sprint 追踪都可以自动化；(3) Agent Gateway 的 JIT access 机制为未来构建有权限边界的 PM-级 agent 提供了安全基础。建议下周安装体验 `pc init`，并探索与现有 Edge OCV/ICM 工作流的接入点。

## 📅 话题二：EMS Agent Workshop 第六期预告

**发起人**：Theo Wang · 2026-05-08 15:16  

**核心内容**：
- **时间**：5/15（周五）下午 3:00–4:00
- **嘉宾**：Sam Yuan
- **主题**：🎯 **Hive — From Personal Agent to Team Agent**

Hive 是基于 Claude Code 的个人 agent，连接 Teams / Slack / Figma / Loop / 日历 / 会议转录，沉淀为五项能力：
- **Tell Anywhere**：Claude Code / Teams / 手机任意端对话，支持语音和图片
- **Insight Report**：一句 brief → design 级别 report 页面
- **Daily Buzz**：一天三次主动把整理好的 brief 推到 Teams，无需主动查询
- **Second Self**：派分身 agent 进群代你回答，敏感数据架构层隔离
- **Hive Mates**：通过 GitHub 双向同步团队知识库，让每个人的 Hive 访问全队记忆

Tracy Chen 在讨论中询问"发布渠道"，Lingyan Zhao 联想到 Hive 是否可以作为渠道，Tracy 确认方向不同。

🧠 **解读 & 应用建议（Edge Mobile PM 视角）**：
Hive 解决了 PM 最痛的两个问题：**信息过载**（Daily Buzz 主动摘要）和**知识孤岛**（Hive Mates 团队记忆共享）。Second Self 的"分身进群代答"能力对 PM 角色尤其有价值——可以在不同渠道同时保持响应而不被淹没。5/15 的分享必看，重点关注 Hive Mates 的团队知识库同步机制是否可以移植到 Edge Mobile 的 oncall/feature 文档管理。
